(주)디엔엠 스마트 MES v4.6 — 간단 적용 안내

1. 관리자 PC에 현재 v4.5.1 프로그램 ZIP 및 업무자료 백업파일 보관.
2. Supabase 시험환경에서 database/16_upgrade_v4_6_purchase.sql 실행 후 17_verify_v4_6_purchase.sql 조회 확인. (기존 v4.5 SQL 14번을 아직 적용하지 않았다면 14번부터.)
3. 수정 패치 ZIP의 모든 파일·폴더를 기존 GitHub 저장소에 병합. 기존 public/config.js는 절대 삭제·교체하지 않음.
4. GitHub Desktop Commit → Push origin → Netlify 배포 완료 → Ctrl+Shift+R.
5. 시험 구매의뢰 1건: 결재→견적의뢰(선택)→발주→품목별 입고→업체 지급액 등록/기간별 조회 검수.

설비가 보이지 않을 때:
  설비·계측관리 → 설비관리 → 등록/사용 상태 확인.
  관리자면 '설비 일괄 사용전환' 버튼으로 이동 → 실제 사용하는 설비만 일괄 사용전환.
  Routing 편집창을 닫고 새로고침 후 다시 선택. 설비-작업자 사전 연결 불필요.
  사용 중인데도 빈 목록이면 운영 DB 조회권한·설비 상태를 점검. 기존 SQL은 무작정 재실행하지 마세요.

주의:
- PRIVATE 자료묶음은 GitHub/Netlify에 올리지 않습니다. v4.4 백업·복원 기능은 유지합니다.
- 발주·결재·정산은 실제 운영에서 확인되지 않았습니다. 시험 프로젝트에서 먼저 검증하세요.
- PDF 저장: 발주서 화면에서 'PDF·인쇄' 클릭 → 인쇄 대상 'PDF로 저장'. 이미지 공유: '이미지 공유'.
