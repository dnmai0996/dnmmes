DNM v4.9.0 검증 결과

1. JavaScript 문법 검사: 57개 파일 통과.
2. Node 자동 테스트: 261개 통과.
3. 기존 백업 무결성: 17,390개 항목 및 컬렉션 해시 통과.
4. PGlite PostgreSQL 호환 시험:
   - 기존 v4.2에서 계정기능 미설치 상태 → 통합 SQL 설치 및 재실행 통과.
   - 기존 v4.3/v4.4/v4.5/v4.6 기능 유지 상태 → 통합 SQL 설치 및 재실행 통과.
   - 실제 첨부 업무기록 7,842건 적재. 작업자 외 기록의 ID·data 변경 없음.
   - 최초 작업자 47명 사용 전환. 추후 미사용 전환 후 SQL 재실행 시 미사용 유지.
   - 47명 고유 계정 연결 및 동명이인 로그인 ID 고유성 확인.
   - 기존 인증계정 충돌 시 자동연결 중단 및 기존 계정 보존 확인.
   - 최초 비밀번호 변경 대기자는 업무접근 불가, 변경 후 새 세션 접근 허용.
   - 사용중지 후 기존 세션 차단 확인.
   - 비관리자 작업자 계정목록 조회 차단, 구매권한 없는 작업자의 구매품목 RPC 차단.
   - 구매 결재자 지정/해제 판정 및 구매 자재·공구 원본 3,099행 조회 확인.
5. DOM 기능 시험(jsdom):
   - 품목명 중간 문자열 검색, 품목 선택과 관련 규격 선택.
   - 목록에 없는 품목/규격 직접입력.
   - 품목 변경 시 이전 규격·단가 제거.
   - 지정 결재자만 목록 표시, 본인/미지정자 제외.
   - 품목 행 추가 시 기존 입력 보존.
6. 연결 설정 보존: public/config.js 및 netlify.toml은 첨부본과 동일.

미검증: 운영 Supabase Auth/Edge/RLS 환경에서의 종단간 실행, 실제 Netlify 배포, Chrome/모바일 시각 배치.
시험용 auth.users/auth.sessions는 Supabase Auth의 전체 구현이 아닌 로컬 테스트 대체 테이블입니다.
이 결과는 운영 사이트 적용 완료를 의미하지 않습니다.
