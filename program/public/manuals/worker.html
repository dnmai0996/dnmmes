로그인과 나의 작업 확인

DNM MES v4.4 · 현장 사용자용

본인 계정으로 접속하여 배정된 작업을 시작하고 실제 작업 결과를 입력합니다. 관리자 메뉴는 사용할 필요가 없습니다.

  1. 관리자가 알려준 MES 주소를 휴대폰 또는 현장 PC의 주소창에서 엽니다.
  2. 본인 이름(ID)과 개인 비밀번호로 로그인합니다. 동명이인은 관리자에게 이름 뒤 번호를 확인합니다. 초기번호 1111을 받은 경우 먼저 새 비밀번호를 정합니다.
  3. 휴대폰에서는 ☰ 메뉴를 열고 생산관리 → 터치 작업입력을 선택합니다.
  4. 작업카드의 품번·공정·설비·Routing 번호·납기를 확인합니다.
  5. 다른 사람의 계정이나 다른 설비의 작업이 선택되어 있으면 입력하지 말고 관리자에게 확인합니다.
기능찾는 곳
큰 버튼·숫자 입력생산관리 → 터치 작업입력
말로 입력생산관리 → 음성 작업입력
내가 기록한 내역생산관리 → 작업일보
도움말화면의 사용방법
개인 비밀번호 변경로그인 후 화면 상단 비밀번호 변경
새 비밀번호는 문자와 숫자를 포함하여 12자 이상으로 만듭니다. 1111은 최초 설정용이며 계속 사용하는 비밀번호가 아닙니다. 작업이 보이지 않으면 관리자에게 배정·배포 확인을 요청하세요.

터치로 시작·종료·완료 입력

생산관리 → 터치 작업입력

작업 시작, 작업 종료, 공정 완료는 의미가 다릅니다. 시작시각·수량을 실제 작업 기준으로 입력하세요.

  1. 내 작업카드에서 해당 공정의 ‘작업 시작’을 누릅니다.
  2. 실제 작업을 마치면 ‘작업 종료’ 또는 ‘공정 완료’를 선택합니다.
  3. 총수량·불량수량을 큰 숫자패드 또는 키보드로 입력합니다.
  4. 표시된 시각·양품수량·불량수량·메모를 확인한 뒤 저장합니다.
  5. 처리 중 표시가 사라진 뒤 작업카드와 작업일보에서 반영 결과를 확인합니다.
버튼·상태사용 예
작업 시작실제 작업을 시작할 때
작업 종료100개 지시 중 오늘 40개를 처리하고 마칠 때
공정 완료해당 공정의 지시수량을 모두 처리했을 때
수량 확인대기정확한 수량을 아직 모를 때. 이후 확인·확정 필요
총수량 100개, 불량 2개이면 양품은 98개입니다. 종료 버튼을 반복 누르거나 같은 작업일보를 다시 만들지 마세요. 공정 완료가 최종 품질합격이나 출하 완료를 뜻하지는 않습니다.

WORKER / 03

음성으로 입력하기

생산관리 → 음성 작업입력

먼저 작업을 선택한 뒤 짧게 말합니다. 인식 결과를 확인한 뒤 저장하므로, 잘못 들린 숫자를 고칠 수 있습니다.

  1. 본인 배정작업을 선택하고 품번·공정·설비를 확인합니다.
  2. 회사에서 허용한 음성처리 안내를 확인하고 마이크를 켭니다.
  3. ‘작업 시작’ 또는 ‘작업 완료, 총수량 100개, 불량 2개입니다’처럼 짧게 말합니다.
  4. 화면에 나타난 문장과 작업구분·수량을 확인합니다. 틀린 부분은 다시 말하거나 직접 수정합니다.
  5. 저장 버튼으로 확정하고, 작업일보에서 결과를 다시 확인합니다.
이럴 때이렇게 처리
소음이 심하거나 숫자를 잘못 인식안전한 위치에서 다시 말하거나 터치입력 사용
마이크 권한 요청회사에서 허용한 경우에만 허용
음성입력 미지원·응답 없음터치 작업입력으로 전환
작업 대상이 불명확입력 중지 → 나의 작업을 다시 선택
음성만으로 실적이 자동 확정되지 않습니다. 브라우저 음성서비스는 외부로 음성을 전송할 수 있어 회사 보안정책에 따라 사용합니다. 작업 중 위험한 자세로 휴대폰을 조작하지 마세요.

WORKER / 04

작업일보 확인과 오류 정정

생산관리 → 작업일보

본인의 작업일자와 공정을 선택하여 시작·종료·수량을 확인합니다. 잘못된 자료는 중복 입력으로 맞추지 않습니다.

  1. 작업일 또는 검색어로 해당 실적을 찾습니다.
  2. 품번·공정·설비·시작·종료·총수량·불량수량을 확인합니다.
  3. 수량 확인대기는 실제 수량을 확인하여 허용된 확정 기능으로 처리합니다.
  4. 수정 권한이 없거나 확정실적에 오류가 있으면 관리자에게 Routing 번호·공정·오류내용을 전달합니다.
  5. 관리자 정정·취소 후 결과를 다시 확인하고 필요한 경우 작업일보를 출력합니다.
확인 항목주의사항
시각7시간 40분과 7.40시간은 다릅니다. 화면에 표시된 시각·시간을 확인
수량불량은 총수량보다 클 수 없음. 모르는 수량을 임의로 0 입력하지 않기
본인 작업다른 작업자 이름을 선택해 대신 등록하지 않기
완료 상태내 공정 완료 후 다음 공정은 해당 담당자가 처리
현장 TV의 진행률은 저장된 실적을 기준으로 갱신됩니다. 중간공정의 수량과 최종 완료량은 구분됩니다. 반영이 늦으면 마지막 갱신시각을 확인하고, 같은 실적을 재등록하지 마세요.

처리 중·접속 문제·업무 마감

사용방법 / 작업진척 대시보드

모래시계 모양의 회전 표시와 대기 커서, 진행 문구가 보이면 작업이 진행 중입니다. 같은 버튼을 여러 번 누르지 마세요.

  1. 하루 종료 전 미종료 작업과 수량 확인대기 실적을 점검합니다.
  2. 실제 수량·시각이 맞는지 작업일보에서 확인합니다.
  3. 관리자에게 인계할 이슈를 기록합니다.
  4. 공용 현장 PC에서는 사용 후 반드시 로그아웃합니다.

복원 완료 후 다시 로그인기존 개인 비밀번호로 로그인하고 나의 작업 재확인
허용된 작업이 없음관리자에게 계정·배정·Routing 배포 확인 요청
비밀번호 분실관리자에게 초기화를 요청하고 다시 본인 비밀번호 설정
통신 오류·저장 결과 불명확목록에서 반영 여부 먼저 조회. 결과를 확인하기 전 새 실적 등록 금지
백업과 복원은 관리자가 수행합니다. 복원 예정이 안내되면 입력을 멈추고, 완료 안내 후 다시 로그인하세요. 사용방법 버튼으로 해당 화면의 짧은 절차를 볼 수 있습니다.
