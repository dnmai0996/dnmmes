# (주)디엔엠 스마트 MES — v4.6.0 구매관리·설비선택 개선

**설치 안내:** `UPGRADE_v4_6_KO.txt` 참고. 기존 `public/config.js`와 운영 DB는 보존합니다.

## 이번 버전

- **구매:** 구매의뢰 → 순차 결재승인 → 견적의뢰서(선택) → 발주서(의뢰 1건당 1건) → 품목별 분할입고 → 업체별 지급금액·지급일 기록 및 기간·업체 집계/CSV.
- **품목 입력:** 품명 일부로 사용 중인 자재·공구 검색, 품명 선택 후 해당 규격 조회. 신규 품명·규격 직접 입력 가능.
- **문서:** 첨부 견적·발주·구매의뢰서 서식을 참고하여 시스템에서 작성한 문서를 인쇄·PDF 저장하거나 PNG로 저장/공유.
- **설비 선택:** Routing 편집 시 등록설비/사용설비 현황과 활성화 경로를 표시. 관리자 설비관리 화면에 일괄 사용전환 바로가기 추가.
- **기존 기능 유지:** 수주→Routing 직접 작성, 설비·작업자 독립/복수배정, 작업 일시중지·재개, 컬럼 정렬, 사용자관리, 업무자료 시점백업·복원.

## 운영 주의

- DB v4.5 설치 후 **`database/16_upgrade_v4_6_purchase.sql`**을 시험 DB에서 검증하고 운영에 적용합니다. `17_verify_v4_6_purchase.sql`은 조회 점검용입니다.
- v4.5 업그레이드가 아직이라면 해당 SQL(14번)을 **먼저** 적용해야 합니다. 이전에 적용한 SQL을 반복 실행하지 마십시오.
- 계정용 Secret key, `public/config.js`, 고객·직원 **PRIVATE 데이터는 ZIP에 없습니다.**
- 실제 Supabase 계정 생성·구매 저장·DB 트랜잭션·Netlify 배포는 이 환경에서 연결 검증하지 못했습니다. 실제 운영 전에 별도 테스트가 필수입니다.
- 초기 가져온 설비가 보이지 않으면 `설비·계측관리 → 설비관리`에서 사용상태를 확인하고 관리자만 `설비 일괄 사용전환`을 수행합니다. 설비·작업자의 사전 연결은 필요하지 않습니다.
