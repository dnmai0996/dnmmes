# (주)디엔엠 스마트 MES — v4.7.0 직원 성명 로그인

기존 v4.6 구매관리·설비 배정·Routing·작업일보·백업·권한 기능 보존.

- 일반 직원: **본인 성명(ID) + 기존 비밀번호**로 로그인. 이메일을 기억할 필요 없음.
- 동명이인: `홍길동`, `홍길동-2` 등 충돌 없이 영구 발급.
- 관리자: 기존 **이메일 + 비밀번호**로 로그인.
- 계정 발급·초기비밀번호 `1111`·직원별 권한·Supabase Auth는 유지.

**v4.5.1 또는 v4.6 → v4.7 업데이트:** `UPGRADE_v4_7_KO.txt` 참고. 

새로 적용하는 SQL은 `database/18_upgrade_v4_7_name_login.sql`이며, 확인용 `database/19_verify_v4_7.sql`은 읽기 전용입니다. 기존 데이터베이스/사용자 기록을 재작성하지 않습니다.

**보안:** 직원 이름→계정 이메일 변환은 Netlify 서버에서만 수행합니다. 인증은 기존 Supabase Auth의 비밀번호 검증과 RLS를 거칩니다. Secret Key는 공개 파일에 포함하지 않습니다. 현재 운영 프로젝트에서의 실제 로그인 검증은 별도 필요합니다.
