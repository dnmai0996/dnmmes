**이름(ID) + 비밀번호** 로그인, 신규 직원 초기번호 `1111`(30분, 최초 변경 필수). 동명이인은 이름-2.

- 작업자 기준정보 1곳에서 사용/중지와 로그인 접근을 연동합니다. 업무이력은 보존합니다.

- 사용자 권한 지정은 기본역할(조회자/일반사용자)과 메뉴별 권한을 함께 저장합니다.
