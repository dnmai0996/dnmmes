## 메뉴
- 독립 대시보드: 대시보드 조회권한이 있는 사용자의 첫 화면
- 수주관리: 고객 수주 → 수주 원본 → 제품 Routing → 원문 후보 → 수주별 초안 → Routing Sheet 관리
- 생산관리: 작업지시·배포현황 → 사전양식 → 터치입력 → 음성입력 → 작업일보
- 구매관리 / 품질관리: 기존 기능을 각각 별도 그룹으로 분리
- 설비·계측관리: 기존 설비관리 / 계측기관리 화면과 권한 유지
- 기준정보 / 초기구축·운영: 나머지 기존 업무 유지

전체 펼치기·전체 접기 버튼을 제거했습니다. 각 그룹 제목으로 열고 닫습니다.
선택 메뉴 자동 노출, 왼쪽 메뉴 독립 스크롤, 현재 표시, 오른쪽 현재 위치 경로를 제공합니다.
모바일은 메뉴 서랍으로 열리며 선택 후 닫힙니다. 데이터는 브라우저에 임시 원장으로 옮기지 않습니다.

## 검증과 한계
- JavaScript 문법검사 32개, 단위·정적 검사 128개 통과.
- Chromium 오프라인 가상자료 DOM 검수 217개 통과. 실제 Supabase·Netlify 네트워크가 아닙니다.
- 실제 장비·운영계정·RLS·DB 동시처리·인쇄·마이크는 이번에 재검증하지 않았습니다.
- SQL·api.js·PRIVATE 자료·기존 Routing/실적 쓰기 로직은 변경하지 않았습니다.
- 설비 예방보전·교정 알림 등 신규 자산업무 엔진은 추가하지 않았습니다. 기존 대장 기능을 새 그룹으로 연결했습니다.
