## 이번 버전 핵심

- 고객수주 Excel 등록 후 해당 주문에서 **Routing Sheet 바로 작성**. 신규 품번은 직접 공정등록, 양산 품번은 기존 공정안을 불러와 검토
- 설비와 작업자는 독립 기준정보. 작업지시마다 유연한 **다수 작업자·여러 설비/여러 작업 중복배정** 지원
- 작업자별 **지시됨/작업 중/일시중지/부분완료/완료**, 날짜별 작업시작·중지·재개·종료 이력
- 기존 가져온 설비·작업자·자재의 **검색결과 일괄 사용전환**(관리자 확인 필요)
- **수주/작업일보/설비/작업자/자재 등 목록 제목 클릭 정렬**: 오름차순 ▲ / 내림차순 ▼. 검색된 전체 결과를 정렬한 다음 30건씩 표시
- v4.4 업무자료 암호화 백업·시점별 복원, v4.3 관리자 직원계정 등록 기능은 유지
