DNM MES v4.5 — 간단 업그레이드 안내

[적용 순서]
1. 기존 DNM MES v4.4의 백업을 받은 후, 현재 public/config.js를 보관합니다.
2. 시험 Supabase에 database/14_upgrade_v4_5.sql을 한 번 실행한 뒤 작업지시·실적을 검증합니다.
3. 운영 전 승인·백업을 확보한 뒤 운영 Supabase에 14 SQL을 적용합니다. 기존 SQL은 재실행하지 않습니다.
4. v4.5 패치파일을 기존 DNM MES GitHub 저장소에 덮어쓰기 → Commit → Push.
5. 기존 Netlify 사이트 배포 완료 후 재로그인하여 테스트합니다.

[관리자 사용 순서]
- 초기구축·운영 → 기준정보 검토·활성화 → 작업자·설비·자재 「검색결과 일괄 사용전환」.
- 수주관리 → 고객수주 → 「Routing 바로 작성」.
- 신규 품번은 공정 직접 입력 / 기존 품번은 같은 품번의 과거 공정 불러오기.
- 공정마다 설비·작업자(복수 가능) 선택 → 초안 저장 → 배포.

[현장 작업자]
- 터치 작업입력 → 본인에게 지시된 작업 선택 → 시작, 일시중지, 부분종료, 완료.
- 한 사람에게 여러 작업/설비가 배정되어도 각 기록은 따로 관리.
- 일주일간 계속되는 작업은 날짜별로 다시 시작·중지·종료 등록.

[확인할 사항]
- 기준정보·기존 로그인·실적·백업자료를 자동으로 삭제하지 않습니다.
- 현재 v4.4용 12 SQL이 설치된 프로젝트여야 합니다.
- 실제 Supabase 적용·동시등록 시험은 아직 수행하지 못했으므로, 운영 데이터에 적용하기 전 시험 DB에서 확인하십시오.
- 프로그램 내 추가 설명은 각 화면의 「사용방법(Help)」에서 확인하십시오.
