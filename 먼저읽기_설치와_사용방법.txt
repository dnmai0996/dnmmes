디엔엠 클라우드 MES v4.9.2 | 기존 4.9.1 운영 시스템 업데이트

1. 운영 중인 MES의 관리자 화면에서 ‘초기구축·운영 → 백업·복원’으로 들어가 현재 업무자료를 백업합니다. 업데이트 중에는 구매 등록을 잠시 멈춥니다.
2. 이 ZIP을 다운로드 폴더에서 압축 해제합니다. database 폴더의 23_upgrade_v4_9_2.sql을 메모장으로 열어 내용 전체를 복사합니다.
3. 현재 DNM Supabase 프로젝트 → SQL Editor → 새 쿼리에서 붙여넣고 Run을 누릅니다. Success가 표시되면 다음 단계로 갑니다. 오류가 표시되면 해당 메시지를 확인한 뒤 진행합니다. 이 SQL은 하나의 트랜잭션으로 수행되며 완료 후 재실행도 가능합니다.
4. GitHub Desktop 상단에서 기존 dnmmes 저장소 선택 → Repository → Show in Explorer. 열린 폴더에 원래 public 폴더와 netlify.toml 파일이 있는지 확인합니다.
5. 방금 압축을 푼 곳에서 public, server, netlify, tools, database, supabase 폴더와 netlify.toml, package.json을 함께 복사해 4번의 폴더에 붙여넣습니다. 같은 이름의 파일은 교체를 선택합니다. 압축을 푼 바깥 폴더가 아니라 그 안의 항목을 복사합니다. 기존 폴더는 지우지 마세요. 기존 public/config.js가 그대로 있어야 합니다. ZIP에는 덮어쓰기용 config.js가 없습니다.
6. GitHub Desktop → Summary에 ‘MES 4.9.2 구매 및 공정코드 개선’ 입력 → Commit → Push origin. Netlify에서 해당 배포가 Published인지 확인하고 MES를 Ctrl+F5로 새로고침하여 관리자 계정으로 로그인합니다.
7. 초기구축·운영 → 사용자별 권한·전결 → 구매담당자 행에서 ‘구매담당자 지정’. 해당 직원은 사용 중이고 구매 메뉴 조회가 가능한 일반사용자 또는 관리자여야 합니다. 구매 결재자는 기존 권한 설정에서 별도로 지정합니다. 기존 4.9.1 로그인용 Edge Function은 이번 업데이트에서 다시 배포할 필요가 없습니다.

업무 적용
• 구매의뢰 작성: 참고 구매처와 예상단가는 공란 가능. 미정 단가는 의뢰 금액 계산에서 0원입니다. 품목·수량·단위 및 실제 결재자를 입력합니다. 구매담당자 이름은 별도 확인란에 자동 표시됩니다.
• 구매담당자가 구매요청·결재 → 상세·결재·문서 → 내용 확인을 누르면 담당자와 시각이 기록됩니다. 결재자는 담당자와 별도로 승인할 수 있습니다. 둘 다 완료되면 발주할 수 있습니다. 담당자 교체 시 미확인 의뢰는 새 담당자에게 인계됩니다.
• 과거 의뢰: 모든 결재자가 아직 처리 전이고 첫 결재자가 현재 구매담당자이며 다음 결재자가 있을 때, 관리자 상세 화면의 ‘기존 첫 결재를 담당자 확인란으로 전환’을 사용할 수 있습니다. 이미 처리한 의뢰는 기존 결재 이력을 유지합니다.
• 발주서 발행: 실제 구매처와 품목별 발주단가를 입력합니다. 구매의뢰서에는 상신 당시 참고 금액이, 발주서에는 확정 발주금액이 출력됩니다.
• 품목별 입고: 입고 품목을 선택하면 발주단가가 표시됩니다. 공시단가가 바뀌었으면 이번 입고의 확정단가로 고칩니다. 분할 입고 건마다 다른 단가를 적용할 수 있습니다. 합격수량만 정산하며 반품은 원입고 단가로 차감합니다.
• 정산: 순입고 공급가액에 의뢰서의 부가세율을 적용한 금액으로 증빙을 대사합니다. 발주별 입고·지급 잔액에서 연결된 지급액과 잔액을 확인합니다. 발주 미지정 지급은 업체 지급내역에서 확인합니다.
• 공정 기준정보 → 코드 정정·삭제: 새 코드 입력 → 영향 확인 → 대상 건수 대조 → 확인. 연결된 제품 Routing, 공정 후보, 주문별 Routing 공정 및 작업일보에 반영합니다. 작업순번(010 등)과 검사코드(M 등)는 별도 항목입니다. 예전 자료에 공정코드가 없으면 공정명·유형·검사코드가 유일하게 일치하는 자료를 연결합니다. 모호한 연결이나 코드 중복은 중단합니다. 미참조 공정만 삭제할 수 있습니다. 변경 후 다시 조회·출력한 문서에 적용되며 이미 내보낸 PDF·종이문서는 재출력이 필요합니다.

적용 확인 예
서로 다른 테스트 계정으로 의뢰 → 담당자 확인 및 결재 → 3개를 단가 100원에 발주(부가세 10%, 330원) → 2개를 120원, 1개를 150원에 입고 → 첫 입고에서 1개 반품 → 1개를 140원에 재입고. 대사금액은 (120 + 150 + 140) × 1.1 = 451원입니다. 실제 운영 자료 대신 시험용 자료를 사용하세요.
