DNM MES 4.10.0 변경사항 및 검증 결과
작성일: 2026-11-12
기준: 제공받은 dnmmes(1).zip의 저장소 루트 public (4.9.5)

반영사항
1. 민수 수기 수주: Shop Order No / Heat Code 및 PDF 표제 정보 입력.
2. 민수 LOT·Routing 별도 메뉴: 자동 분할, 월별 YYMM-0001 공통 순번.
3. 첨부 PDF 중심의 민수 전용 인쇄. 엑셀은 실적조회 구조 참고이며 기존 자료 자동등록 없음.
4. 미착수 취소 후 재작성, 불량 최종종결. 취소번호/이력은 보존.
5. 분할 미리보기에서 개별 LOT 수량 수정. 생성 후에도 조건에 맞춰 수량 변경.
6. 민수 실적조회: LOT별/수주별 공정 누적 및 실제 작업일보, CSV.
7. 원지시 배정을 보존하고 실제 작업자·설비를 작업일보별 저장.

운영 규칙
- 방산 공정 순서 준수. 민수도 기본 순서 준수, 필요한 공정만 순서 무관 선택.
- LOT 번호는 작업 예정일의 월 기준이며 취소한 번호는 재사용하지 않음.
- 생성은 한 번에 최대 200 LOT, 전체 5,000 공정. 큰 수주는 이번 계획수량을 나눠 작성.
- 미착수 취소는 수주 계획 가능 수량으로 반환. 작업·검사 이력이 있으면 취소 불가.
- 불량 종결은 이미 투입한 LOT 수량을 배정량에 유지하며 추가 작업을 차단.
- 진행/미확정 작업은 종료·확정한 뒤 LOT 수량 변경 또는 불량 종결.
- 처리수량 미만 축소, 초과배정, 검사·출하 이력에 어긋나는 변경은 서버에서 거부.
- 개별 공정 누적수량을 모두 합해 총 생산량/납품량으로 사용하지 않음.

검증
- Node.js 자동검증: 267개 통과.
- 독립 PostgreSQL 18.6: 기존 158개 + 신규 73개 검증 통과.
- 실제 다중접속 경쟁 3개: 동일키 중복 생성 방지, 수주량 초과 방지, 월 순번 충돌 방지.
- SQL27 연속 2회 적용 성공, 기존 업무행 전체 JSON digest 보존 확인.
- 실제 V410Controller DOM 동작 29개 통과.
- JavaScript 43개 파일 구문 검사 및 상대 import 경로 확인.
- 설정·계정·배포 관련 8개 파일 원본 바이트 동일 확인.
- WeasyPrint A4: 17공정 1쪽, 60공정 4쪽 검토. 출력 PDF LOT 바코드 독립 ZXing 재인식.
- Chromium 실행은 작업환경 정책 제한으로 확인하지 못함. 화면 입력은 DOM으로 검증.

검증 범위
최신 운영 데이터베이스 백업은 이번 첨부에 없으므로 실제 운영행과 직접 대조하지 못했습니다.
첨부 프로그램의 SQL 이력을 구성한 별도 데이터베이스에서 검증했습니다.
운영 Supabase/GitHub/Netlify에 직접 적용하거나 운영 데이터/환경설정을 변경하지 않았습니다.

보존 항목
public/config.js, netlify.toml, supabase/config.toml, 계정·백업 서버 함수는 변경하지 않았습니다.
배포 압축에는 이러한 설정·서버 파일을 포함하지 않아 PC의 현재 값이 덮어써지지 않습니다.
SQL27은 기존 4.9.5(SQL26) 이후 적용하며, 초기 스키마/이전 SQL 전체 실행은 필요하지 않습니다.

요청한 삭제 기능은 감사이력 보존을 위해 미착수 취소로 구현했습니다.
취소 자료는 정상 진행 목록에서 제외되며 취소 이력에서 확인할 수 있습니다.
