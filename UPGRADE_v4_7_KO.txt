(주)디엔엠 스마트 MES v4.7 — 작업자 이름(ID) 로그인

[반영내용]
- 직원: 본인 성명(ID) + 기존 비밀번호 로그인. 이메일 암기 불필요.
- 동명이인: 홍길동, 홍길동-2처럼 자동 구별(실제 ID는 관리자 목록 확인).
- 관리자: 기존 이메일과 기존 비밀번호 유지.
- 초기번호 1111, 최초 개인 비밀번호 설정, 기존 계정·작업실적·권한 유지.

[적용 순서]
1) 현재 업무자료를 백업하고 기존 프로그램 ZIP 보관.
2) Supabase SQL Editor에서 미적용 SQL만 순서대로 실행:
   - 현재 v4.5.1이면 16_upgrade_v4_6_purchase.sql → 18_upgrade_v4_7_name_login.sql
   - 현재 v4.6이면 18_upgrade_v4_7_name_login.sql만 실행
   ※ 이미 적용한 SQL을 다시 실행하지 않습니다.
3) 수정 패치 ZIP 전체를 기존 GitHub 폴더에 병합하고 Commit → Push.
4) Netlify 배포 완료 후 Ctrl+Shift+R.
5) 관리자 → 초기구축·운영 → 사용자 등록·초기화에서 직원별 이름(ID) 확인.
   아직 등록하지 않은 작업자는 기존 방식대로 계정 등록이 먼저 필요합니다.
6) 직원 이름 + 기존 비밀번호 로그인 시험. 기존 초기화 대기 직원은 이름 + 1111 시험.

[중요]
- 기존 public/config.js를 삭제하거나 덮어쓰지 마세요.
- 기존 Netlify 환경변수 2개는 변경하지 않습니다.
- 이메일은 인증시스템 내부에 보존하지만 직원은 로그인 시 입력하지 않습니다.
- 프로그램 업무자료 백업은 그대로 유지됩니다. 이번 SQL은 업무자료나 비밀번호를 변경하지 않습니다.
- 실제 Supabase/Netlify 운영계정에서의 성공 여부는 검증 전이므로 시험 직원으로 먼저 확인하세요.
