# v4.0 기능 통합표 / 원본 대조 범위

## 원본 검토 결론
- Cloud Admin v3.0: 공통관리 전체 소스, Supabase SQL, 테스트 포함.
- Login Patch 3.0.1: 로그인 오류·연결진단·세션 처리 패치. 현재 public/api.js는 해당 패치 유지.
- rc2_import_message_fix: 전체 MES가 아닌 9개 파일의 부분 패치. app.js, demo.js, 서버 API·DB 스키마, 원래 Routing/생산/품질 구현은 없음.
- 따라서 ‘전체 RC2의 모든 기능/화면이 동일하다’는 검증은 불가능합니다. 아래는 실제 확인·포팅·신규 구현의 구분입니다.

## 포함하지 않은 기능
- 전체 RC2 원본에 있을 수 있는 미제공 기능의 동일 구현 확인
- 구 MySQL 운영자료 자동 이관, 완전한 MySQL schema 호환
- PDF/OCR 자동 추출, Excel 매크로, 원본 성적서 레이아웃 완전 복제, 서명·인증 자동 발행
- 다창고·재공품 이동 원장, 자동 생산최적화, 자동 재작업 계획/공정분할·동시병렬 작업
- Netlify Blobs, 사내 Node.js/MySQL 서버, Ollama·로컬 STT 서버
- 금융 송금/세금계산서 발급/외부 ERP 자동 연계
- 데이터 일괄초기화·자동복원: 오삭제 방지를 위해 미포함

위 제외항목은 존재하지 않는 기능을 숨긴 것이 아니라 제공된 패치의 확인 한계와 이번 구현의 범위를 명시한 것입니다.
