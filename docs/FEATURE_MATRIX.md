## 유지
GitHub/Netlify/Supabase, v4.0.2 native-fetch constructor 수정, 기존 계정/제품/거래처/수주/구매/품질/메모/감사이력.
구매·결재·전결·발주·입고·반품·정산·품질·출하 기능은 기존 흐름 유지.
제품·거래처 수정은 v4 업무권한 master와 DB 정책을 일치시킴.

## 명시적 제외/한계
사내 MySQL 전환, Ollama/로컬STT연결, 고객서명·도장 복제, 공식품질성적서 자동발급, XLSM매크로 실행, PDF자동판독 제외.
신규/양산은 Excel 원본 상태와 별도. 검토완료 템플릿 유무로 안내하며, 주문의 실제 작업구분은 작성자가 확인.
제품 Routing 수정은 기존 배포본/작업일보에 소급하지 않음. 실적발생 경로의 임의교체는 차단.
