## 데이터 의미 보존
- 수주의 A~CD 82열 보관, C열/AO열의 동일한 ‘상태’ 제목 별도 키 유지.
- 원본에 없는 PO행번호를 계약번호품목번호·PR순번으로 대체하지 않음.
- 원본 ‘협력업체명’을 고객명으로 자동 대입하지 않음.
- 설비 원본의 작업자 이름은 확정된 로그인계정/가능공정 배정과 별개로 보존.
- 공구 원본에 없는 단가/단위는 구매요청에서 명시적으로 확인.
- 제품별 공정명은 템플릿 초안으로만 사용. 가공/검사/외주/소재 유형과 순서는 사람이 확정.

## PDF·공정도·서식 반영 범위
현장 작업 구성도, 작업일보, RoutingSheet, 품질성적서, 고객 발주서, 통합 XLSM 서식은 업무항목/관계/검증 요건을 설계하는 참고자료로 사용했습니다.
도형 공정도에서 치수/공정조건을 자동 추출하거나 제품 설계·가공 파라미터를 생성하지 않습니다.
품질보증서·시험성적서는 문서대장/참조정보/기록사본 기능이며 첨부 원본의 서식이나 매크로를 자동 복제하지 않았습니다.
민수·방산 설비별 작업자 파일은 값 읽기를 확인했으나 직원에게 계정/권한을 자동 부여하지 않습니다.
