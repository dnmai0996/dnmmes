## 반드시 확인할 사항
- 민수/방산 설비별 작업자 파악현황의 66개 작업자칸이 모두 비어 있음. 사람 배정은 생성하지 않음.
- 작업자는 주민등록번호, 주소, 연락처, 성별, 나이 등을 등록자료에서 제외. 로그인 계정/비밀번호/권한은 만들지 않음.
- 공구카탈로그와 자재 마스터의 1549행은 같은 항목의 연결용 표현이지 3098개 실물재고가 아님. 수량재고는 만들지 않음.
- 템플릿 367개와 후보 415개도 중복 제품수가 아님. 같은 품번의 출처별 후보를 보존한 것.
- 8개 품번은 우선 후보끼리 상충하여 기본템플릿 미생성. 원문 후보 선택 필요.
- 현재 수주 10건은 세 품번. 82027803-1 두 건, PLA82024303 여섯 건은 검토대기 초안 보유. A30006103 두 건은 030/050 등 원문 후보 선택 필요.
- 품명 순번의 하이픈과 실제 시트명 밑줄 차이는 후보로만 연결하여 이슈에 기록.
- 공정번호가 원문에 없을 때 생성순번을 사용했다는 플래그 보존. 원문번호와 구분.
- 작업시간/작업수량/작업자/날짜 공란, 원문 #REF!은 추정하지 않음.
- 제품 표시명 우선순위는 PARTS_MASTER→XLSM품명→공정표→수주. 다른 이름/사업은 part_detail에 병기. 담당자가 수정 가능.
- 별도 PRIVATE 검토대장 15시트는 협의용. Excel 상태변경이 DB에 자동반영되지는 않음.

## 기록 방법
각 행 sources에 원본 파일 ID, 시트, 행번호를 보존. 묶음 sources에 파일명·SHA-256 보존. 과거원문과 신규운영자료를 분리.

Excel 공정번호 표시형식도 대조했습니다. 예: 저장값15/16 + 원본 형식000 → 표시코드015/016. JSON에 code_raw와 code_format을 함께 보존합니다.

## 로컬 재변환 (선택)
Python 표준 라이브러리만 사용합니다. 원본 10개 파일의 이름과 시트구조는 첨부본과 같아야 합니다.
```text
python tools/build_master_bundle.py "D:\DNM_Source" "D:\DNM_Private_New"
```
새 원본의 구조나 기준일이 다르면 이 변환규칙을 검토해야 합니다. 이 도구는 Excel 검토대장을 재작성하거나 운영 DB에 접속하지 않습니다. 기존 출력폴더는 덮어쓰지 않습니다.
