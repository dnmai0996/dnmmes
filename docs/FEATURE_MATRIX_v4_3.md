# v4.3 기능 반영표

| 요청 | 구현 | 비고 |
|---|---|---|
| 프로그램 관리자 로그인으로 작업자 계정 등록 | 사용자 등록·초기화 페이지, 작업자 화면 바로가기 | Supabase Auth는 저장소로 유지 |
| 로그인 사용자 체크 | 직원별 체크, 본인 이메일 확인 모달 | 매핑과 버전 검증 |
| ID 본인 이메일 | 공백 정리·소문자 정규화, 정확한 메일 입력 | 이름으로 메일 추정하지 않음 |
| 1111 초기화 | 관리자 재인증, 30분 설정전용 초기번호 | 실제 Auth 암호를 1111로 낮추지 않음 |
| 사용자 비밀번호 변경 | 최초 설정 필수, 로그인 후 상단 자율변경 | 현재 비밀번호 확인 |
| 기존 계정·권한·업무 보존 | 기존 이메일 재사용, 삭제 없음 | 신규 계정만 최소 작업자권한 |
| 사용 중지 | 체크 해제 확인 후 자료접근 차단 | 기존 이력 삭제 없음 |
| 보안 | Netlify server-only 관리자키, private 해시/티켓, DB 세션 가드 | 실제 운영 DB/API 검수 필요 |

기존 v4.2.1의 접이식 메뉴·설비/계측기·검색·Routing/작업일보·조회/등록/수정 권한을 유지합니다.
사내 MySQL·Ollama로 전환하지 않으며 별도 사용자 인증 DB를 신규 도입하지 않습니다.
