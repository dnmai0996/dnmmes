# DNM MES v4.5.1 간단 운영순서

## ① 관리자의 기본 준비

1. 초기구축·운영 → 기준정보 검토·활성화: 설비/작업자/자재를 검색하여 **일괄 사용전환**(실사용·재직 여부 확인 후); 중지 자료만 별도 수정.
2. 사용자 등록·초기화: 작업자의 실제 이메일로 로그인 등록, 최초 비밀번호 변경 안내.
3. 사용자별 권한 확인. 설비와 작업자 간 고정 연결은 **필수 아님**.

## ② 수주 → 작업지시

1. 수주관리 → 고객수주: **Excel 가져오기** 또는 신규 수주등록.
2. 해당 수주의 **Routing 바로 작성** 선택.
3. **신규 품번:** 공정 직접 입력 / **양산 품번:** 동일 품번의 기존 공정안 활용 후 변경.
4. 공정마다 설비 및 한 명 이상 작업자를 작업지시별로 선택; 여러 작업자/여러 작업/여러 설비 중복배정 가능.
5. Routing 검토·저장·배포. 이전 작업실적은 보존.

## ③ 현장 작업자

1. 본인 이메일로 로그인 → 터치 작업입력 → 본인 지시 작업 조회.
2. **지시됨 → 작업시작 → 작업 중 → 일시중지 → 재개 → 부분종료/공정완료** 순서로 필요에 맞게 처리.
3. 실제 **작업일자**는 작업자가 입력, 수일~1주간 작업은 날짜별 기록. 긴급작업이 생기면 진행 중 작업을 일시중지하고 우선 작업을 진행한 후 재개.
4. 작업일보에서 본인의 이력과 수량 확인.

## ④ 경영진·관리자 확인

- 대시보드에서 수주별·설비별·작업자별 진척 확인. 공정 처리수량과 최종 품질합격/출하수량은 구분.
- 목록에서 열 제목 클릭 **▲ 오름차순 → ▼ 내림차순**. 수주, Routing, 작업일보, 설비, 작업자, 자재 등 검색결과 전체를 정렬.
- 관리자 업무자료 백업·시점복원은 기존 v4.4 기능이며, 실사용 전 시험 복원으로 검증.

## 데이터와 검증 범위

- 기존 운영 데이터와 SQL을 자동으로 삭제하거나 초기화하지 않음.
- v4.5의 DB 확장은 `database/14_upgrade_v4_5.sql`, v4.5.1 정렬에 추가 SQL 없음.
- 가상 API 기반 브라우저/자동검사 완료; 실제 Supabase에서 복수 배정·실적·백업 복구는 현장 시험 필요.
