# Routing에서 설비 목록이 보이지 않을 때

1. 설비·계측관리 → 설비관리에서 총 등록 건수 및 사용중/사용중지 건수를 확인합니다.
2. 사용중지일 경우 관리자 권한으로 `설비 일괄 사용전환`을 눌러 `기준정보 검토·활성화`로 이동하고, 실제 사용 중인 설비를 확인하여 사용전환합니다.
3. Routing 편집창을 닫고 새로고침 후 다시 엽니다.
4. 모든 설비가 사용중인데도 조회되지 않으면 실제 계정의 설비 조회권한·DB 레코드 상태를 확인해야 합니다. 단순 SQL 재실행으로 해결하려 하지 않습니다.
5. 설비와 작업자는 별도의 기준정보입니다. 작업지시에서 각각 선택하며 사전 연결은 필요 없습니다.
