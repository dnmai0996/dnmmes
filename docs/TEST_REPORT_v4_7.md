# DNM Cloud MES v4.7.0 — 로그인 ID 개선 검증

- 이전 버전: DNM v4.6.0 구매·Routing·업무백업 소스 그대로 유지
- 변경 범위: 로그인 표시, 서버의 성명→인증계정 매핑, 등록 시 고유 ID, 관리자 목록과 도움말
- `npm run check`: JavaScript 문법검사 통과 (54개 파일)
- `npm test`: 단위·정적 테스트 246개 통과
- 모의 Chromium desktop(1366px), mobile(360px): 일반 직원 이름 로그인, 초기비밀번호 설정, 현장 화면 진입 12개 확인
- 동일 성명: SQL 고유 인덱스·트리거에 따라 -2/-3 번호를 덧붙이도록 설계 (실제 Postgres 인스턴스 미실행)
- 기존 계정 재생성·비밀번호 변경·DB 데이터 재입력 없음. 새로운 이름 매핑은 보안 전용 스키마에만 추가됨
- SQL `18_upgrade_v4_7_name_login.sql` 및 `19_verify_v4_7.sql`은 운영 Supabase 미적용
- 실제 Netlify/Supabase에서의 end-to-end 인증·다중 계정·동명이인 SQL 실행은 미검증. 운영 배포 전 시험환경 검수 필요

## 운영 확인 항목
1. SQL18 실행 후 읽기 전용 SQL19에서 미배정 이름 0건 확인
2. 기존 관리자 이메일 로그인 성공, 기존 직원 비밀번호 보존 확인
3. 기등록 직원 본인 성명(ID) 로그인 성공, 비등록 직원은 기존 등록 후 확인
4. 동명이인 두 계정(ID·-2) 분리 확인, 임의 타인 비밀번호 로그인 실패
5. 1111 초기화 후 최초 비밀번호 설정, 이전 로그인 세션 차단 확인
