### 브라우저 점검 상세
- v4.0.2 constructor/native fetch 수정 유지와 모의 로그인·연결진단
- 업무 메뉴 24개와 해당 도움말 열기
- 수주 12열, 입력 즉시 키워드 검색, 실제 파일 미리보기
- 템플릿 연결·공정 추가/삭제·진행/종료 필터·기준정보 등록 폼
- 로그인 작업자 본인 배정 작업, 시작 요청, 터치 수량 숫자패드
- 음성 메뉴의 인식문 입력·수량 해석·확인 후 요청 전송(실제 마이크 아님)
- Routing A4 인쇄 및 화면 크기별 레이아웃

`BROWSER_TEST_RESULT.json`은 각 점검명, `UNIT_TEST_OUTPUT.txt`는 실제 Node 출력입니다.
모의 API는 SQL 로직을 실행하지 않습니다. 따라서 화면 점검 통과를 데이터베이스 권한/업무처리 성공으로 해석하면 안 됩니다.

## 실행하지 못한 검사 — 운영 전 필수
1. 실제 Supabase 또는 PostgreSQL에서 `06_upgrade_v4_1.sql` 실행·재실행과 트랜잭션 검증
2. 실제 Auth 로그인과 RLS·전결·담당자별 접근 차단·동시저장 검증
3. 실제 Netlify 배포·기존 운영자료 호환성·실제 백업 복원
4. 실제 휴대폰/터치PC 마이크 인식률, 소음·브라우저별 호환성
5. 현장 20명 부하, 프린터별 출력, 대형TV 장시간 운용

이 환경에는 PostgreSQL 실행기가 없어 DB 통합시험을 실행하지 못했습니다. GitHub Actions의 임시 PostgreSQL17 검사와 `tests/sql/integration_v41.sql`을 제공하였으나, 원격 CI를 대신 실행한 것은 아닙니다. 먼저 시험 프로젝트에 적용하고 운영 승인을 받으십시오.

## 시험자료 보호
브라우저 API·로그인·화면·인쇄 PDF는 가상자료입니다. 실제 수주파일은 로컬 읽기만 수행하고 저장 API로 전송하지 않았습니다. 실제 첨부자료·고객값·계정 비밀번호·운영 config.js는 배포 ZIP에 포함하지 않았습니다.
