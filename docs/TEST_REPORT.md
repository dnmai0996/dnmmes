# DNM v4.0 검증 기록

검증일: 2026-10-28 / 코드 버전 4.0.0

## 수행한 검증
1. JavaScript 문법검사: **21개 파일 통과** (node --check).
2. Node 단위/정적 테스트: **47개 통과**.
   - 기존 v3.0.1 로그인·설정·세션·음성 관련 24개 유지.
   - 수량/시간/CSV/음성확인/수주미리보기/요청 재확인 등 18개.
   - SQL 원문 구조·접근제어 선언 관련 5개. **이 5개는 PostgreSQL 실행검증이 아님.**
3. Chromium 렌더링 및 모의 API UI 점검: **41개 확인 항목, JS 오류 0개**.
   - 로그인→v4컨텍스트, 25개 메뉴, 대시보드3모드, 신규수주.
   - 팝업 내 오류/입력동결/같은 UUID·같은 payload 재요청.
   - 실제 수주 XLSX 10행/82열 미리보기·확인항목 검증.
   - Routing 상세 및 단계추가, 선택 결재선 요청구성.
   - 실제 대형 공구 XLSX 1,549행 미리보기.
   - 320/390/768/1440px 화면에서 문서 전체의 가로넘침 없음. 표 내부 스크롤은 의도한 동작.
4. 실제 첨부 Excel의 파싱·차단행 검증: SOURCE_REVIEW.md의 결과표 참조.

## 시험환경 범위
- Node 22.16.0, Chromium/Playwright.
- 브라우저 시험은 관리정책상 페이지 탐색이 제한되어 about:blank에 실제 CSS/통합 ES모듈 코드를 로드한 방식으로 실행.
- Fetch는 가상 Supabase 응답으로 대체. Worker는 테스트용 같은스레드 shim 사용. XLSX 파서 자체는 실제 파일/실제 DecompressionStream 사용.
- 실제 배포시 모듈 로딩/보안헤더/Worker 생성은 별도로 점검해야 함.

## 아직 수행하지 않은 검증
- 실제 Supabase 프로젝트의 SQL 실행/함수 컴파일 및 RLS·트랜잭션 동작.
- 실제 Auth 이메일 로그인/refresh, Netlify 운영배포.
- GitHub Actions에서 PostgreSQL 통합검증 실행.
- 실제 iPhone/Android 마이크·음성 인식/TTS, 20명 동시사용·부하·장기데이터.
- 기존 RC2 전체 소스 대비 동일성(원본 전체 미제공).

## 제공한 추가 자동검증
.github/workflows/verify.yml:
- 별도 임시 PostgreSQL 17에 테스트용 auth schema/role 생성.
- v3 스키마와 가상 기존자료 적재 → v4 migration 2회 실행.
- 기존자료 보존, 직접변경 차단, 익명 함수권한 차단.
- 수주/라우팅/배정/작업/수량확정/최종검사/출하/마감 시나리오.
- 구매 순차결재/필수결재 보호/발주/부분입고/반품/증빙대사/지급기록 시나리오.
- 실제 authenticated 역할의 RLS 조회 범위 검사.

위 테스트 파일을 제공한 것과 실제 실행하여 통과한 것은 다릅니다. GitHub Actions가 초록색으로 완료되고 시험 Supabase 검수를 마친 다음 운영 DB에 반영하십시오.
`tests/sql`은 임시 시험DB 전용이며 실제 운영 Supabase에서 실행하면 안 됩니다.
