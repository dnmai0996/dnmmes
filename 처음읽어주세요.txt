DNM MES 4.10.1 업데이트 - 먼저 읽어주세요

1. 현재 앱의 업무자료를 백업하고 GitHub 저장소 폴더를 별도로 복사합니다.
2. 기존 Supabase 프로젝트 SQL Editor에서 SQL을 적용합니다.
   - 4.10.0 SQL27 수정본이 아직 성공하지 않았다면 database/27_upgrade_v4_10_0.sql 먼저 실행.
   - 이어서 database/28_upgrade_v4_10_1.sql 실행. 이미 SQL27이 성공했다면 SQL28만 실행.
   - 초기 설치 SQL과 과거 SQL 전체를 재실행하지 마세요. 오류가 나오면 그 결과를 먼저 확인합니다.
3. GitHub Desktop → 현재 DNM 저장소 → Repository → Show in Explorer.
4. 이 압축의 public 폴더와 package.json 두 항목을 위 저장소 폴더에 복사합니다.
   같은 폴더는 병합하고 같은 파일은 덮어씁니다. 기존 폴더를 삭제하지 마세요.
   기존 public 폴더가 보이는 위치에 붙여 넣으며 public 안에 public을 넣지 마세요.
5. Commit → Push origin → Netlify Published 확인 → 앱 로그아웃 → Ctrl+F5 → 재로그인.
6. 탭·로그인 화면의 4.10.1과 수주 잔량, 작업일보 수정·비고 기능을 확인합니다.

이 압축에는 config.js/Netlify/Supabase 연결 설정과 계정 서버 함수를 넣지 않았습니다.
PC의 현재 파일과 환경변수를 그대로 사용합니다. dnm-accounts 재배포는 필요하지 않습니다.
연차 테이블, 사원번호, MES 직원 ID, 연차 연결을 재생성하지 않습니다.
SQL 설치만으로 기존 업무 데이터를 다시 생성하거나 삭제하지 않습니다.
