(주)디엔엠 스마트 MES v4.5.1 — 간단 적용 안내

[운영 DB가 v4.4인 경우]
1. 관리자 PC에 현재 프로그램과 업무자료를 각각 백업합니다. 기존 public/config.js는 그대로 보존합니다.
2. 시험용 Supabase에서 database/14_upgrade_v4_5.sql 적용 → 작업지시/작업일보/복원 검증.
3. 시험 통과 후 운영 DB에 14_upgrade_v4_5.sql을 한 번만 적용합니다. 기존 SQL은 다시 실행하지 않습니다.
4. 패치 ZIP을 기존 GitHub 저장소에 그대로 병합(폴더 public 아래 public 중복 금지) → Commit → Push → Netlify 배포확인 → 재로그인.

[운영 DB가 이미 v4.5인 경우]
- SQL 실행 없이 패치 파일만 위 4번과 같이 반영합니다. 4.5.1의 표 정렬에는 새 DB 변경이 없습니다.

[사용법]
- 표 제목 클릭: 1번 오름차순(▲), 다시 클릭하면 내림차순(▼). 검색조건 전체에 정렬한 후 페이지 분할합니다.
- 고객 수주 → Excel 등록 → 해당 수주의 Routing 바로 작성 → 설비·작업자 지정 → 배포 → 현장 작업 → 작업일보/대시보드.
- 설비/작업자/자재는 초기구축·운영 → 기준정보 검토·활성화 → 검색결과 일괄 사용전환 (실사용 여부 확인 후).
- 계정·비밀번호, 백업·복원, 구매·품질 기존 기능 유지. 추가 안내는 각 화면 사용방법(Help)에 있습니다.

[꼭 확인]
- 기존 수주/작업실적/권한/계정/백업 파일은 다시 등록하거나 삭제하지 마세요.
- 실제 운영 Supabase SQL, 복수 작업자 동시등록, 시점복원은 아직 현장 검증 전입니다. 우선 시험 환경에서 확인하세요.
- 파일에는 고객/직원 PRIVATE 원본 데이터와 public/config.js, 서버 비밀키를 포함하지 않습니다.
